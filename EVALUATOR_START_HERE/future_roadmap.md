# Future Roadmap & Project Enhancements

This document outlines the advanced architectural improvements, database changes, and user experience enhancements that we would bring to the Skylark BI Agent if given more than the prototype's 6-hour timeline.

---

## 1. Advanced Database Architecture (Supabase / Postgres)

*   **Move entirely to Postgres**: Migrate the local SQLite schema to a production PostgreSQL database. 
*   **Persistent Chat History**: Currently, refreshing the browser clears the chat history. We would add a `chat_sessions` and `chat_messages` table to permanently store conversational turns per user account.
*   **Vector Database (RAG)**: Store data dictionaries, sector metadata, and company PDFs (like standard contract terms or drone spec sheets) in a PGVector extension. This would allow founders to ask questions about both telemetry metrics and sales stats in a single prompt.

---

## 2. Dynamic Cross-Board Analytics

*   **Cross-Board Joins**: Currently, the Deals and Work Orders boards are queried independently. Since **52 of the 58 work order items share names with the deals database**, we can join these datasets on `Deal Name` to calculate advanced metrics:
    *   **Overruns**: Flag work orders where the actual billed value has exceeded the original estimated deal value.
    *   **Pipeline Delays**: Identify won deals that have not yet had a corresponding work order generated in the operational tracker.
    *   **BD vs Ops Personnel Performance**: Correlate sales owners (`Owner code` from Deals) with operational managers (`BD/KAM Personnel code` from Work Orders) to track which sales routes lead to the most successful deliveries.

---

## 3. Real-Time Data Sync (WebSockets)

*   **Webhooks Integration**: Setup webhooks in monday.com that ping our FastAPI backend whenever an executive updates a cell or changes a deal status.
*   **WebSocket Dashboard Updates**: Push updates from the server to the browser dynamically using WebSockets. When a deal is moved to "Won" in monday.com, the KPI numbers on the frontend dashboard would slide upward in real-time without requiring a page refresh.

---

## 4. User Experience (UX) Enhancements

*   **Streaming Responses (Server-Sent Events)**: Implement token-by-token streaming for the chat endpoint, allowing the response text to print dynamically as it is generated by Gemini (similar to ChatGPT or Claude).
*   **Export Formats**: Add PDF export templates for the Executive Briefings. This would allow users to download a formatted report complete with Recharts charts embedded as high-resolution images.
*   **Confidence Scoring & Query Clarifications**: If a query is ambiguous, display a confidence score (e.g. `Confidence: 75%`) and render selectable chips showing recommended follow-up questions to help the founder refine their query.
